# Spacepointe Landing

Next.js + TypeScript + Tailwind CSS landing page template inspired by the provided Execoore-style reference.

## Getting started

```bash
npm install
npm run dev
```

## What’s included

- App Router setup
- Tailwind-driven responsive hero
- Header, CTA buttons, and feature cards
- Self-contained portrait illustration built with CSS
